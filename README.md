# Brex concept

How an expense agent could handle a receipt it can't fully read: what it says, what it asks, and how the person fixes or undoes it.

An unofficial concept by Gaurav Basantani (https://gauravbasantani.com), based only on public information. Not affiliated with Brex. The receipt, merchant and numbers are made up.

Live page: https://gauravbasantani.github.io/brex-concept/
